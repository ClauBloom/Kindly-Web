# Kindly Web

Kindly Web 是一款开源的 Chrome 浏览器插件（Manifest V3）。它会在你浏览网页时自动扫描评论区（目前已适配 Bilibili），并调用大语言模型将带有攻击性、阴阳怪气或负面情绪的评论，实时重写为和谐、友善且理性的表达。让你在享受内容的同时，不被戾气影响心情。

## 特性

- **劫持式改写**：直接拦截 B 站评论/弹幕 API 响应，不依赖页面 DOM 结构。
- **原地改写 + Hover 原文对照**：评论先以原文显示、改写完成后原地替换，悬停可查看原文；也可切换为「仅浮层对比」模式，不动页面原文。
- **屏蔽优化**：用户可以选择是否展示未经插件处理的弹幕和评论。可以选择提前屏蔽掉相关评论，等待处理完毕后再展示，亦或者先显示原文，等待处理完毕后替换
- **强度可调**：温和（mild）/ 适中（moderate）/ 强力（strong）三档改写力度。
- **隐私优先**：评论原文仅发送至**你自己配置**的 LLM API；扩展自身不收集、不上传任何数据。
- **智能队列**：按标签页独立排队、全局并发限流、指数退避、超时熔断、失败自动暂停，避免打爆 API。
- **改写缓存**：相同内容只请求一次（本地 LRU 缓存，上限 2000 条）。

## 数据流向与隐私

```
评论原文 (+可选昵称) ──> 你配置的 baseURL 指向的 LLM API ──> 改写结果
```

- API Key 只存储在本机 `chrome.storage.local`，且**只在扩展的 Service Worker 中读取**，从不进入网页进程。
- 扩展本身不收集任何数据，不上传任何数据；关闭/卸载即停止全部请求。
- **威胁模型说明**：`chrome.storage` 未加密，本机 profile 可读。本扩展防护的是**网页脚本嗅探**（恶意网页无法读取你的 Key 与改写内容），不防护本机攻击者。如需更高安全等级，请自行评估加密存储方案。

## 安装（从源码构建）

需要 Node.js ≥ 22 与 pnpm。

```bash
pnpm install        # 安装依赖并生成类型
pnpm build          # 构建产物输出到 .output/chrome-mv3
```

然后在 Chrome 打开 `chrome://extensions` → 开启「开发者模式」→「加载已解压的扩展程序」→ 选择 `.output/chrome-mv3` 目录。

开发模式（热更新）：`pnpm dev`。

## 使用

1. 首次安装会自动打开 5 步引导：选择 LLM 服务商 → 填入 API Key → 测试连接 → 选择改写偏好 → 完成。
2. 点击工具栏图标打开 popup：总开关、强度切换、队列状态。
3. 打开 B 站任意视频页评论区，评论即被自动改写；悬停可查看原文。

支持的服务商预置：OpenAI、DeepSeek、智谱 GLM、阿里云百炼，以及任意 OpenAI 兼容的自定义地址（自定义域名首次使用时需授权扩展访问该域名的网络权限，可在引导/设置页内一键授权）。API Key 支持填写多个（逗号分隔），请求自动轮询分摊限流。
